# FDE 技术与产品学习

一套以问题、机制和证据为线索的自学资料网站。技术路线为 00 → A → B → C → D → E → F → X，产品与业务作为后续或按需阅读内容。

网站包含 59 个章节、9 册教材、31 支基础理解视频，以及章节记忆表和知识关系图。视频解释一个问题，正文提供完整范围；不要求每一章把所有材料重复看一遍，也不把浏览完成当作掌握。

这是个人整理的学习项目，不是官方课程网站。资料中的命令、路径和合成业务场景用于说明机制，应根据自己的实验环境使用。公开站点不连接作者的个人学习进度、聊天记录或云端笔记。

## 使用

从网站首页按章节阅读，或按当前问题选择视频。章节中的 PDF、记忆表与关系图可以单独打开。网站保留原资料的内容和必要来源，网页只调整阅读与查找方式。

网页是静态文件，不需要账户或数据库。最近打开的位置仅保存在当前浏览器中，不上传到服务器，也不表示已经学会。

## 本地查看

在仓库目录运行：

```sh
python scripts/preview_server.py --port 8080
```

然后打开 `http://127.0.0.1:8080/`。预览服务支持视频时间点跳转，并且只监听本机。应通过网页地址查看；直接用文件预览器打开 HTML 时，正文加载和相对链接可能不可用。

验证公开资源：

```sh
python scripts/validate_site.py --site site --report qa/validation.json
```

验证器检查目录对应、资源存在、发布清单中的文件身份和可移植链接。它不证明真人学习效果，也不能替代实际浏览器中的阅读、播放和移动端检查。

## 发布到 GitHub Pages

1. 将本仓库推送到自己的 GitHub 仓库 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
3. 运行 **Publish learning site** 工作流，成功后从 Pages 页面取得网址。

发布根目录是 `site/`，地址和资源均支持 GitHub 项目站点的子路径。GitHub Actions 会先验证资源，再上传站点；不会在部署时读取作者电脑或生成新的教学视频。

`site/media/` 包含当前公开的 PDF、视频、字幕及关系图。更新材料时同步更新 `site/data/` 中的资源清单，不直接修改旧校验记录来掩盖不一致。

## 维护范围

源站只有学习资料和前端页面。个人记录、作者工具、历史成片、验证截图与临时文件不属于公开内容。没有云端学习进度同步、在线执行代码或自动评估掌握程度的功能。

网站代码和资料在未另行注明许可时不自动授予商业使用或再许可权；引用来源保留其原有许可。发现内容错误，可以通过本仓库的问题反馈说明章节及具体位置。
